# Security Policy

## Supported Versions

Only the latest major version of MYNA is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.1.x  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in MYNA, please do **NOT** open a public GitHub issue.

Instead, report it privately by emailing [sahilsingh107433@gmail.com] or reaching out directly to the maintainer. We aim to acknowledge reports within 48 hours.

## Scope

Please refer to `docs/THREAT_MODEL.md` before reporting. Certain behaviors—such as a `control` guest executing dangerous commands in Native Mode—are expected behaviors of a shared terminal, not vulnerabilities.
